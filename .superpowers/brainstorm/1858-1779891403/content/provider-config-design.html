配置存储

providers.json

存储所有供应商配置，支持导入/导出

配置项说明

  • 供应商名称：自定义显示名称
  • API类型：DeepSeek / OpenAI兼容 / 其他
  • API Key：认证密钥（加密存储）
  • 端点URL：API地址（DeepSeek默认：https://api.deepseek.com）
  • 默认模型：如 deepseek-chat、deepseek-coder
  • 参数配置：temperature、max_tokens等
