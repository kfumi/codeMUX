# Codex 技能完整路径设计

## 目标

修复 Codex 使用技能时发送的指令链接格式，使技能链接指向实际的 `SKILL.md` 文件；Claude Code 的现有格式保持不变。

## 根因

技能命令注册时已经保存了技能磁盘目录，但作曲器序列化命令时只使用命令名称作为链接目标，导致 Codex 收到 `[$skill](skill)`，而不是实际文件路径。

## 设计

- 为命令触发项传递当前智能体类型，避免序列化器无法区分 Codex 与 Claude Code。
- 当智能体为 Codex 且命令存在技能文件路径时，将命令序列化为 `[$skill](技能目录/SKILL.md)`。
- 当智能体为 Claude Code 时继续使用当前 `[$skill](skill)` 格式。
- 当 Codex 技能缺少文件路径时回退到命令名称，避免生成无效链接。
- 文件和目录引用、内置命令及其他智能体行为保持不变。

## 验收标准

1. Codex 选择具有磁盘路径的技能后，发送内容包含完整的 `SKILL.md` 路径。
2. Claude Code 选择同一技能后，发送内容仍使用技能名称作为链接目标。
3. 缺少磁盘路径的 Codex 技能仍可正常发送。
4. 相关定向测试和项目构建通过。
