# 04 — 焦点感知：后台完成也亮角标 + 回焦自动清除

**What to build:** 修掉最常走、却完全没有提醒的那条路径 —— 用户正开着某个 Session，把窗口最小化或切去别处，Turn 跑完，回来却什么都没看到。现在「标记未读」对当前活跃 Session 直接跳过，所以这种情况永远不会有角标。

改成：只有当**应用处于前台焦点**且该 Session 是活跃 Session 时才跳过标记。也就是说「开着这个会话、但窗口在后台」照样标未读、照样亮角标。

同时补上回焦语义，避免蓝点卡在一个自己正看着的会话上：因「活跃但无焦点」被标上的未读记入一个独立的后台补记集合；窗口重新获得焦点且仍停在该 Session 上时自动清除它。用户离开期间去看过别的会话，则保留未读作为回来处理的提醒。手动「标记为未读」的 Session 不进这个集合，因此不会被回焦误清。

前台判定收敛为一个可注入的小工具：有 `document` 时读焦点状态；没有 `document`（Node 测试、SSR）时视为前台，以保持既有 store 行为与现有测试不变。
