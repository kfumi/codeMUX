# 01 — Windows 任务栏红点（最小闭环）

**What to build:** 一条完整的端到端路径：只要有 Session 处于未读，Windows 任务栏上 CodeMUX 的应用按钮右下角就出现一个纯红圆点；打开那个 Session，红点消失；全部读完，红点彻底消失。这是整个功能的第一根 tracer bullet —— 未读真值、计数口径、渲染层到壳的同步通道、壳侧像素渲染与 overlay 接线在这一次全部打通。

计数口径与侧栏状态点同源：只数仍存在于当前会话列表里、且未归档的 Session。角标不受系统通知开关影响。红点不闪任务栏、不抢焦点、不显示数字（16px 下不可读）。计数为 0 时移除角标而不是画一个空点。

壳侧的角标图像必须能在 Node 里单测：4× 超采样的预乘 alpha 圆点、按标签缓存的徽章图、以及 Windows 10 与 Windows 11 的圆心分叉（Win11 画布内居中；更早的系统在画布内右下锚定，补偿旧任务栏 overlay 的落点差异）。overlay 的无障碍描述携带具体数量。主窗口首次可显示时，壳再应用一次当前值，覆盖「渲染层先同步、壳还没就绪」的时序。

验收只需要现有的「标记为未读」菜单项就能走完 —— 不依赖后台完成那套逻辑（那在 04）。

**Blocked by:** None — can start immediately

**Status:** done
