# 05 — 删除 / 归档时清理未读，消除幽灵角标

**What to build:** 删除或归档一个未读 Session 之后，角标计数立刻相应减少，不会留下一个点不掉的幽灵红点。

现在删除会话与归档会话这两条路径都不清理未读集合，被删掉的 Session 会一直留在集合里 —— 侧栏里已经没有它的蓝点落点了，角标却还亮着。这与 01 的计数口径是同一个问题的两面：口径只数「仍在会话列表里」的 Session 能挡住已删除的，但归档是另一条路径，且归档后的 Session 仍然存在于归档列表里，必须在动作发生时显式移除。

**Blocked by:** 01 — Windows 任务栏红点（最小闭环）

**Status:** done（代码完成；手工验收未执行）

- [x] 删除会话时同步从未读集合中移除这些 Session
- [x] 归档会话时同步从未读集合中移除该 Session
- [x] 计数口径明确排除已归档 Session（与侧栏一致：归档区不参与常驻提醒）
- [x] 单元测试覆盖：删除未读会话后计数减少、归档未读会话后计数减少、删除非未读会话不影响计数
- [ ] 手工验收：制造两个未读 → 删除其中一个 → 角标计数相应变化；归档一个未读会话 → 角标不再把它算进去
