# 02 — 托盘红点（Windows / Linux）

**What to build:** 把同一个未读信号做到托盘图标上：有未读时，图标右上角合成一个红点；计数归零时恢复原始图标。这补齐了任务栏覆盖不到的场景 —— 窗口关到托盘后没有任务栏按钮，任务栏 overlay 根本不可见，此时提示完全由托盘承担。

红点尺寸独立于任务栏角标（约 7px 逻辑直径），同样用超采样抗锯齿；图标同时提供原生 1x（16px）与 2x（32px）两个 representation，避免把硬边合成图交给 Shell 盲缩。原始图标只加载一次并缓存，合成结果只画红点、与计数无关，因此只渲染一张长期复用。没有托盘实例时是 no-op（macOS 虽然也建托盘，但托盘角标只在 Windows / Linux 上生效，macOS 由 Dock 角标承担）。
