# 03 — 一轮一张卡片

**What to build:** 让一条 User Message 只挂出一张产物卡片，位置在该轮最后一条助手消息之后。

现状是实时管道每完成一次运行时内部收尾就产出一张卡片，而一条 User Message 之下运行时可收尾多次，因此同一个提问会挂出多张各说各话的卡片。核查在生产库中确认过：存在 1 条 User Message 对应 **6 张**卡片的会话，多数会话在 1~2 张。

本工单把轮次边界统一成产品语义上的一轮，并让整轮统计以「该轮首次改动」为基线。

单独成单的理由：这是**唯一**改变四个 Agent Kind 轮次收尾时机的改动，也是本次风险最高的一处。放在最后一个门，是为了让前一个工单不断往汇总器里加输入时不必反复重跑轮次边界回归；同时让失败定位无歧义。

**Blocked by:** 02

- [x] 四个 Agent Kind 行为一致（Claude Code、Codex、OpenCode、pi）
