# 02 回合结束刷新环境信息

**What to build:** 一个回合结束（settle）后异步刷新受影响项目的环境信息快照，使浮层/钉住的摘要自动反映智能体在这一回合里的改动，无需用户手动重开或切换面板。回合进行中不主动刷新——沿用 spec 里「结算而非实时更新」的取舍。

**Blocked by:** 01（环境信息快照 store）——本票依赖 01 的 `refresh(projectPath)` 动作与按项目键控的缓存。

**Status:** done

- [x] 订阅 agent store 的 `isRunning` 由 true→false 边沿（回合结束，先例：`agentStore.ts` 现有的 `useAgentStore.subscribe`），解析受影响的项目路径
- [x] 回合结束后，当前项目的摘要面板自动显示新的变更统计/分支，无需手动重开或切换档位
- [x] 回合进行中不触发刷新（不做实时更新）；不引入 TTL 或手动刷新控件
- [x] 回合结束触发的刷新复用 store 的在途去重，不产生重复扇出的 git 调用
- [x] 仅有项目缓存时才刷新（未访问过的项目不因回合结束凭空取数）
- [x] 就近测试：断言回合结束边沿恰好触发一次 `refresh`；非回合结束的状态变化（如流式增量）不触发
