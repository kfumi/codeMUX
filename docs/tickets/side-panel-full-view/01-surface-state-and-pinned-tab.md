# 01 — 完整视图 surface 状态机与固定「对话」标签

**What to build:** 点「展开预览」进入完整视图后，面板 tab 栏第一位固定出现「对话」标签（会话图标 + 当前会话标题），它不能被关闭、不参与右键菜单与「关闭其他/全部」，且仅在有活动会话时渲染。点击它激活「对话 surface」——侧面板 store 新增一个随 scope 快照保存的布尔，激活它**不**改动 activeTabId，切回面板标签时恢复原选中。所有「激活/打开面板标签」的 store 动作统一把 surface 切回面板；完整视图下关闭最后一个面板标签不再收起面板，而是落到对话标签；退出完整视图的三条路径（收起面板、恢复面宽、清空标签）都复位 surface。对话标签激活期间，终端/浏览器标签按「未激活」判定，原生浏览器视图隐藏（避免原生层盖住下一票要做的对话层）。

本票完成后：对话标签的出现/切换/关闭收尾行为全部可用，并能在 store 与组件两层测试里验证；对话内容真正显示进面板内容区由 02 完成。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 完整视图生效（面板打开且展开）且有活动会话时，对话标签渲染在 tab 栏第一位；无活动会话或新建草稿态不渲染
- [ ] 对话标签显示会话图标与会话标题（随重命名/自动命名更新），无关闭按钮、无右键菜单项，不受「关闭其他/关闭所有」影响
- [ ] 激活对话标签的动作置位对话 surface 且不改 activeTabId；从对话标签切回面板标签恢复离开前的选中
- [ ] 现有的激活标签与全部打开标签动作（审查/终端/浏览器/计划/diff/文件/子智能体）在设置 activeTabId 的同时切回面板 surface
- [ ] 完整视图下关闭最后一个面板标签：面板保持展开、对话标签激活、activeTabId 置空；非完整视图维持「收起面板」现状
- [ ] 收起面板、恢复面宽、关闭所有标签三条退出路径复位展开态与对话 surface；退出不写任何其他布局状态
- [ ] 对话标签激活时终端/浏览器标签视为未激活；原生浏览器视图的可见性判定为「无激活 browser 标签」（沿用现有联动链路）
- [ ] 对话 surface 布尔随 scope 快照保存与恢复，后退/前进导航语义与面板开合、激活标签一致
- [ ] store 单测覆盖以上状态转移；侧面板组件测试覆盖标签渲染条件、第一位顺序、不可关、点击切换（两个现有测试接缝）
- [ ] 改动范围内的 vitest（store 与 workspace 相关目录）通过
