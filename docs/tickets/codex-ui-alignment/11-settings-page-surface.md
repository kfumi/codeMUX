# 设置页对齐 Codex —— 字重、左导航分组与表单风格

**Status:** implemented

## 目标

设置页此前是按「Codex 视觉语言」改过一轮,但只覆盖了 7 个分页,且三处与 Codex 差得最明显:
整页的字偏浅、描述啰嗦、左导航是一条平铺列表。本工单把设置页升格为**独立一档表面**,
按本机 Codex 桌面端(26.1007.9446.0)的实测值逐项对齐。

## 实测依据(截图取样 + asar 抠值)

来自用户提供的 Codex 设置页截图(1482×946,逐像素取样)与应用包内明文前端:

| 元素 | Codex 实测 | 我们(改前) |
|---|---|---|
| 页标题「常规」 | `#0d0d0d` 墨色,32px/590 | 墨色 ✓,26px |
| **分区标题「权限」** | **`#0d0d0d` 墨色**,13px/510 | `muted-foreground` 灰 ✗ |
| 行标签「默认权限」 | `#0d0d0d` 墨色,13px/510 | 墨色 ✓ |
| 行描述 | `#616161` 次级,12px/16px 行高 | 次级 ✓,行高 26px |
| **导航项「外观」** | **`#0d0d0d` 墨色** | `muted-foreground` 灰 ✗ |
| 导航分组「个人」 | `#858585` 弱色,与项同字号 | 无分组 |
| 卡片 | 白底 + 1px `#ececec` 描边,圆角 20px | 白底 + 发丝边 ✓ |
| 分隔线 | 卡片 x 555→1282,分隔线只画 572→1265(**两侧内缩 16px**) | 通栏 ✗ |
| 行内边距 / 间距 | `px-4 py-3`、标签↔描述 2px、文字↔控件 24px | `py-3.5`、6px、16px |
| 下拉控件 | 32px 高、透明底 + 内描边、13px、窄扁箭头 | 36~40px、实心底、16px 箭头 |
| 开关 | 轨道 32×20、关 = ink 10%、滑块白 | 轨道 36×20、关 = `--input` |
| 行内小按钮 | 28px、ink 5% 底、无边框 | 36px、描边 |
| 正文字重 | `--font-ui-weight: 430` | 400 |

「看起来浅」的三个成因因此确定:导航项与分区标题用了次级灰、正文基准字重低 30。

## 决策

1. **字号只在自己的刻度里挑档**:页标题 `text-ui-heading-lg`(30≈Codex 32)、导航标题
   `text-ui-heading-sm`(22≈18)、行标签/描述保持 `text-sm`/`text-xs`。刻度本身不动,
   外观全局设置照旧生效。
2. **三档文字按 Codex 语义重排**:导航项与内容区分区标题一律墨色,只有描述用次级、
   导航分组标题用弱色。这是「不再发浅」的主修。
3. **正文基准字重 400 → 430**(`globals.css` 的 `body`):Codex 的 `--font-ui-weight`。
   可变字体(Win11 Segoe UI Variable / Geist / Inter)真的渲染 430,静态字体回落 400。
   `font-medium` / `font-semibold` 仍是 500 / 600,不引入 Codex 的 510 / 590。
4. **左导航成品字形**:标题 → 搜索框 → 四组分组(通用 / 智能体 / 能力 / 数据与系统)。
   搜索是 Codex 的样式(药丸形、墨色 6% 底、无描边)与行为(过滤标签与副标题、空结果提示、
   回车跳首个命中、Esc/清除按钮);分组空时不渲染光标题;原来的底部固定三角(系统工具/日志/关于)
   并入最后一组。
5. **页头改成 Codex 形态**:大标题 + 短副标题,**取消 sticky 与背景模糊**(Codex 的标题随内容滚走)。
6. **卡与行**:`SettingsCard` 统一画两侧内缩 16px 的发丝分隔线(行不再各自带 `divided`,
   不会漏线也不会双线);行 `px-4 py-3`、标签↔描述 2px、文字↔控件 24px;
   卡片表面**不动**(实测 Codex 就是白卡 + 发丝描边)。
7. **控件三件套**:`SelectTrigger size="sm"`(32px / 透明底 / 13px / 窄箭头)、
   `Switch` 轨道 32px + 关态 ink 10% + 滑块统一白、`Button size="xs"`(28px)与
   重定义的 `secondary` 变体(ink 5% 软按钮,Codex 的 `color: secondary`)。
8. **描述文案规则**:一句话讲「它做什么」,目标 ≤ 24 字、上限 40 字或两个短句;
   不写「在哪儿点」的教学句;危险项保留最短的完整警示句;结尾不用句号。
9. **迁移范围 = 表单型页面**:常规、通知区、浏览器控制、图片识别、电脑控制、Git、快捷键、
   关于、系统工具、已归档对话、日志、MCP / Skills 的列表外壳。密集面板(模型配置的主从分栏、
   智能体的选项卡、使用统计的图表)只吃新字号与颜色,信息结构不动。

## 落地

新增 `SettingsSection`(小标题 + 卡)与 `SettingsRow` 的 `stacked` / `htmlFor` 两个变体:
前者用于路径、多行输入这类塞不进 240px 右列的控件,后者把行标题与控件真正关联起来
(`<label htmlFor>`),读屏与「点标题聚焦控件」都成立。

`SettingsRow` 的 `divided` 属性删除 —— 分隔线归卡片管,调用方少一个可以忘的开关。
