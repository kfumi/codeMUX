# 04 图标导航栏与标题栏外壳

**What to build:** 窗口最左侧出现一条窄图标导航栏，承载会话、自动化、工单三个顶层视图，设置钉在底部；侧栏随之变成「随导航栏当前项切换的上下文侧栏」。标题栏从「只跨内容区」改成「跨全宽的顶部条」，窗口控件换成 Windows 原生样式，和系统里其它应用看起来一致。标题栏承载的会话头、侧栏开关、主题切换按钮**一个都不丢**。

**Blocked by:** 01, 02

**Status:** 实现 done，Win11 贴靠实测待人工确认

- [x] 窄图标导航栏（约 56px，实施时实测校准）承载：会话（高亮当前项）、自动化、工单；设置钉在底部
- [x] 自动化与工单从侧栏顶部按钮**提级**到导航栏，功能不减少
- [x] 侧栏随导航栏当前项切换内容：选中会话时是现有的项目/会话两级树，选中自动化/工单时是对应列表
- [x] 标题栏改为跨全宽的顶部条（侧栏不再与它平级），位于导航栏之上
- [x] 窗口控件换成 Windows 原生样式方块按钮，加入后退/前进，标题栏高度与字重对齐系统 caption
- [x] 标题栏里的会话头、侧栏开关、主题切换按钮保留，只改成与 caption 一致的低调样式
- [x] 项目/会话两级树、agent 选择入口位置、侧栏宽度可拖拽行为**全部不变**
- [x] 窄屏（移动端）下导航栏正确降级，不出现挤压或溢出
- [ ] 实测 Win11 贴靠布局：从主进程窗口样式（`WS_CAPTION` + `WS_THICKFRAME`）推断自绘标题栏不失去贴靠，**真机悬停最大化按钮的确认仍未执行**（见 08 的人工清单）
- [x] 就近测试覆盖：导航栏切换顶层视图、设置置底、选中态、侧栏内容随之切换

## 代码评审修复

- 导航栏焦点环原本是 `ring-ring/45`，压在近白表面上约 2:1，达不到 WCAG 2.2 SC 2.4.11 对焦点指示的 3:1；改为不透明 `ring-2 ring-ring` + 外偏移。
- 导航栏的文字色从 `text-[hsl(var(--sidebar-fg))]` 换成语义工具类（`text-foreground` / `text-muted-foreground`），与侧栏其余部分统一 —— 此前它是全仓最后一处还对 sidebar token 写任意值的文字。
