# 02 — 扩展 schema：项目根表、回填、会话目录范围列

**What to build:** 项目从单一路径扩展为根集合的数据基础，同时不改变任何用户可见行为。

新增项目根表，保存每个项目的根路径、顺序与是否主根；迁移把每个项目现有的路径回填成它唯一的主根。新增会话的目录范围列（可空 JSON 数组），供生成型会话冻结目录集合使用。daemon 提供单一的「取项目主根」访问器，所有后续代码都通过它读主根，而不是直接读项目行。

项目的对外形状增加根列表与主根字段；旧的单一路径字段暂时保留为「主根的镜像」，让尚未迁移的读取点继续工作，也让编译器在收缩阶段能列出全部待改点。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 新增项目根表：项目 ID、根路径、顺序、是否主根；主键为（项目 ID, 根路径），天然实现项目内按绝对路径去重
- [ ] 迁移把每个项目的现有路径回填为主根（顺序 0、标记为主根），旧库升级后不丢项目
- [ ] 主根唯一性由写入事务保证：同一项目最多一条主根记录
- [ ] 会话新增目录范围列，默认为空；空表示「每次运行实例重建时按项目当前根现算」
- [ ] 存在单一的「取项目主根」访问器，后续代码不直接读项目行上的路径
- [ ] 项目对外形状包含根列表（路径、顺序、是否主根）与主根；旧路径字段作为主根镜像保留
- [ ] 单测覆盖：旧库迁移、回填结果、项目内去重、主根唯一性、空根集合的读取
