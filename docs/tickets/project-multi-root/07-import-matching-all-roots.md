# 07 — 导入会话按全部根匹配

**What to build:** 导入历史会话时，候选不再只按项目主根匹配，而是按项目的全部根匹配，并修掉一个既有缺陷：当前的前缀判断会把 `frontend-old` 误判为 `frontend` 的子目录。

判断改为路径段边界：候选目录等于根，或候选目录以「根 + 分隔符」开头；Windows 上大小写不敏感。

导入的会话保留它原生存储里的工作目录，而不是被改写成项目主根。原生会话历史按工作目录存放，改写路径会让它失联，也会破坏智能体种类切换与恢复。
