# 04 — 编辑项目：增删文件夹、切换主根、移除语义

**What to build:** 一个「编辑项目」对话框，用户可以改项目名、添加文件夹、把任意文件夹设为「主要」、移除文件夹、删除整个项目。

移除语义是这张票的核心：

- 移除主根后，剩余根中顺序最小的自动继任，不需要用户额外操作。
- 移除非最后一个根时，不改变任何已有会话的工作目录，界面提示有多少条会话会继续在原目录运行。
- 移除最后一个根时，不再允许保存一个空项目，而是切到「删除项目」流程，并提示将被连带删除的会话数量。
- 删除项目会连带删除其名下全部会话，与那些会话的工作目录是否仍在根内无关。

文件夹列表显示目录名，悬停显示完整路径；同一项目内出现同名文件夹时在列表内消歧。列表顺序即添加顺序，不支持拖拽；「设为主要」只改变主根标记，不改变顺序。
