# 03 — 多选文件夹创建多根项目

**What to build:** 用户点「添加项目」时，系统目录选择器允许多选；选中后在创建对话框里确认项目名称与根顺序，第一个文件夹默认是主根，可用「设为主要」调整（只改标记、不重排顺序）；确认后项目一次建成，侧栏出现一条带「多文件夹」标识的条目。重启应用后根集合仍在。

创建请求从「名称 + 单个路径」改为「名称 + 根路径数组 + 可选 `primaryRoot`」。`roots` 顺序即添加顺序；不传 `primaryRoot` 时第一个根为主根。

这是第一条用户可感知的端到端切片：从选择器 → 请求契约 → 落库 → 侧栏展示。
