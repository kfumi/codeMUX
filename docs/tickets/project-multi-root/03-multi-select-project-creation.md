# 03 — 多选文件夹创建多根项目

**What to build:** 用户点「添加项目」时，系统目录选择器允许多选；选中的第一个文件夹成为主根，其余成为附加根；项目一次建成，侧栏出现一条带「多文件夹」标识的条目。重启应用后根集合仍在。

创建请求从「名称 + 单个路径」改为「名称 + 根路径数组」。前端在选择完成后不再立刻落库单个路径，而是把整个数组提交。

这是第一条用户可感知的端到端切片：从选择器 → 请求契约 → 落库 → 侧栏展示。

**Blocked by:** 02

**Status:** ready-for-agent
