# 08 — 生成型会话冻结目录集合与主根

**What to build:** 定时任务与 Work Task 这类「生成型会话」在任务创建时把当时的全部项目根与主根冻结下来，之后无论项目根或主根怎么改，这些后台任务都在冻结的范围内执行。

理由：这类会话可能在几天后无人值守地运行。如果目录集合实时跟随项目，用户整理项目结构就会悄悄改变一个后台任务的写入范围；主根变化还会把任务带到另一个目录。

普通会话不受影响，仍然在每次运行实例重建时按项目当前根现算。

任务级保存全部根（`directory_scope`）与主根（`working_path`）；运行建会话时用冻结主根作为会话 cwd，再用冻结根集合减去它得到会话的附加目录数组。会话级数组与普通会话的附加目录形状一致，消费端只需要一种形状。冻结主根不可用时本次运行失败并报明确错误，而不是悄悄换到新目录。升级前创建的旧任务在首次运行时补冻结。
