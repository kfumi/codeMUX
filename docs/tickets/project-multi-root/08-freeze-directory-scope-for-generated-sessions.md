# 08 — 生成型会话冻结目录集合

**What to build:** 定时任务与 Work Task 这类「生成型会话」在创建时把当时的目录集合冻结进会话，之后无论项目根怎么改，这些后台任务都在冻结的范围内执行。

理由：这类会话可能在几天后无人值守地运行。如果目录集合实时跟随项目，用户整理项目结构就会悄悄改变一个后台任务的写入范围。

普通会话不受影响，仍然在每次运行实例重建时按项目当前根现算。

冻结的数组不含会话自己的工作目录，与普通会话的附加目录形状一致，消费端只需要一种形状。
