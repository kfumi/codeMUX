# 09 — 收缩：删除项目单一路径字段与全部读取点

**What to build:** 项目行上的单一路径字段正式删除，主根只存在于项目根表。这是 expand–contract 的收缩阶段：前八张票已经把新形态建好，此票删掉旧形态，确保没有任何代码还能读到第二真相源。

删除前必须把所有剩余读取点迁到「取主根」访问器，包括 Git 面板的路径参数、worktree 创建、Git 环境快照缓存键、项目 Skill 扫描、导入匹配、移动端与浏览器前端。项目的对外形状去掉单一路径字段，消费方改读主根字段。编译器的类型错误就是迁移清单。

Git 相关能力这一版只服务主根，不做跨根操作。

**Blocked by:** 03, 04, 05, 06, 07, 08

**Status:** ready-for-agent

- [ ] 迁移后删除项目行上的单一路径字段，主根只存在于项目根表
- [ ] 项目对外形状不再包含单一路径字段，消费方改读主根
- [ ] Git 面板、worktree 创建、Git 环境快照缓存键全部改读主根
- [ ] 项目 Skill 扫描只扫主根
- [ ] 桌面、浏览器与移动端前端全部通过主根解析项目目录
- [ ] 旧库升级到该版本后项目、根集合与会话均可用
- [ ] 全仓库不再有任何地方读取项目行上的单一路径
- [ ] 完整测试套件通过
