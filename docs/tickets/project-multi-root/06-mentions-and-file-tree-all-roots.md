# 06 — `@` 提及与文件树覆盖全部根

**What to build:** `@` 文件提及、文件树与项目浏览都覆盖项目的全部根，而不再只看主根。

路径形态是关键：主根下的文件用相对路径插入，附加目录下的文件用**绝对路径**插入。否则附加目录的相对路径会被智能体解析到会话工作目录下，指向错误的文件。候选列表单独显示根名徽标，让用户能分清同名文件。

文件树与项目浏览按根分组展示，让用户看到项目的全貌。
