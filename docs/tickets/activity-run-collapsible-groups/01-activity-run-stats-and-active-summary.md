# 01 — 分类统计与活动摘要投影（纯函数层）

**What to build:** 为连续过程组补齐派生数据层：每个 Activity Run 能给出「探索 / 执行 / 修改 / 其他」分类统计、纯思考回退与活动步骤选择，修改按文件词法去重。本票不改任何 UI，只扩展投影模块输出并以单测锁住全部边界。

**Blocked by:** —

**Status:** done（代码与自动化验证完成；dev:desktop 手工验收未执行）

- [x] 四分类按规范化工具身份判定：探索＝文件/Notebook 读取、列目录、匹配文件、搜索文本、查看图片、网页搜索与读取网页；执行＝终端与标准输入、JS/REPL、浏览器工具、电脑控制及明确执行控制类会话工具；修改＝写入/编辑/批量编辑/Notebook 编辑/应用补丁；计划、待办、技能、未识别内置工具与第三方 MCP 一律归「其他」。
- [x] 内置 MCP 工具先还原内置工具段再分类；第三方 MCP 未命中显式映射时归「其他」，且未知工具不切断分段。
- [x] 修改计数词法去重：统一分隔符、处理 `.` / `..`、保留 Windows 盘符 / UNC / POSIX 根 / 相对路径语义；同一文件重复编辑计一次；一次补丁触及多文件按可识别目标计数；无路径修改按调用次数另行计数，不虚构路径；全程不访问文件系统。
- [x] 每段统计输出：类别顺序固定「探索 → 执行 → 修改 → 其他」，零值省略；混合组不计思考段数；纯思考组输出思考段数（无工具但含非空思考的多步骤组按纯思考组）。
- [x] 活动步骤选择：从后向前找流式思考或输入流式 / 运行中工具，没有则回退最后一个可见步骤；投影只给出步骤身份与状态，摘要文本由消费方按现有单行语义生成。
- [x] 步骤识别与既有口径一致：非空思考块与实际渲染的工具调用各一步；同 `tool_use_id` 重复投影只算一步；缺 id 按可见卡各算一步；不画行事件不贡献步骤也不切段。
- [x] `runKey` 与段身份规则不变，流式追加复用同一段身份。
- [x] 投影测试覆盖：工具别名大小写、内置 MCP 前缀、第三方 MCP、Windows/POSIX/UNC/相对路径去重、多文件补丁、OpenCode 双帧去重、正文 / 问询 / 委派边界、活动项选择矩阵。
- [x] 受影响测试全绿；不涉及 Rust daemon / Sidecar，无需 `build:daemon`。
