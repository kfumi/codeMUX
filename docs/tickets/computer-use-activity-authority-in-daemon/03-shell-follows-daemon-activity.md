# 03 — 壳按 daemon 事件显示与急停：无人值守也看得见、停得下

**What to build:** 壳侧改为跟随 daemon 的活动事件：收到 `computer-use-activity` 就显示/收起提示条，并武装/解除全局 Esc；Esc 触发时只调急停端点（02），不再通知渲染层、也不再依赖渲染层回话。于是「没人开界面」「渲染层从没加载」「浏览器/手机客户端在用」这几种形态下，机器被驱动时提示条照样出现、Esc 照样能停。

工单 18 的壳侧看门狗保留，但守的对象从「渲染层心跳」换成「**daemon 链路心跳**」：控制面链路断了就 fail-hidden —— 收起提示条 + 解除 Esc，绝不留一条按不动的「按 Esc 急停」（今天它守的是渲染层，正好是本设计要去掉的那一层）。

并存期规则（本票必须实现，不删旧路径）：**daemon 是权威，渲染层只能「加」不能「减」** —— 两个来源里任一报「有活动」就保持武装与显示，只有两个都说没有才收起，避免丢 Esc；daemon 不可达时不接管（与今天没有桌面桥接时的行为一致，不回归）。

本票同时写下用户可见说明：CHANGELOG 一条 + 电脑控制指南写明「后台/无人值守的电脑控制会占用本机全局 Esc，提示条在没人开界面时也会出现」。

**Blocked by:** 01 — 活动真值：daemon 自己知道「这台机器正在被驱动」；02 — 急停端点：一次调用把驱动、授权与回合一起停下

**Status:** done

- [x] 不加载渲染层：按一次 Esc 完成 02 的三件事（杀驱动、收回限时授权、打断有活动的回合）

- [x] daemon 链路断开：fail-hidden（不挂着按不动的急停提示）

## Decisions

- **壳不再自己判断「有没有活动」，只做合成与显示**：`apps/desktop/src/computer-use-arming.ts` 是提示条与全局
   Esc 的**唯一出口**。合成规则是 `链路在 ∧ (daemon 有活动 ∨ 渲染层要武装)`：daemon 是权威，渲染层在并存期
   只能「加」不能「减」—— 它报没有不能把 daemon 报的那份减掉，避免两个来源互相抖动时丢 Esc。
- **链路不在就谁都不武装**：唯一能把机器真正停下来的地方是 daemon。daemon 不可达时 Esc 与提示条都是假的，
   所以宁可 fail-hidden，也不挂一条按不动的「按 Esc 急停」——这与「今天没有桌面桥接时不武装」是同一条口径。
- **看门狗跟着来源走（不是整体开关）**：渲染层心跳超时 / 渲染进程 gone 只撤**渲染层那一半**，daemon 报的
   活动不受影响（无人值守驱动正是本设计要覆盖的形态）；daemon 那一半的活性判据是**控制面链路本身**。
- **daemon 链路 = 控制面 WS（含 Ping/Pong 保活）**：daemon 只在活动变化时发事件，这条链路平时没有流量，
   所以按 15s 发一次协议级 ping、容忍 45s 未回 Pong 就主动断开（对端卡死/假死也能被判死）；daemon 的会话与
   控制面两条 WS 循环都显式回 `Message::Pong`（`crates/daemon/src/companion/server.rs`），这是既有实现。
   15s/45s 的量级只为兜「对端不再回应」，不会把 loopback 上的正常连接判死。
- **旧 daemon 的兜底是「404 才退回」**：新端点不存在 → 通知渲染层打断回合 + 杀驱动（旧行为），其它失败
   （断连、5xx）原样抛出，不当作旧版本。写成「任何失败都退回」会把 daemon 断连误判成版本问题。
- **`shell-bridge` 退成薄壳**：IPC 通道名与载荷形状不变（`preload` / 渲染层桥契约不动），合成逻辑搬进
   Node 可测模块；测试也随之分层 —— `shell-bridge-arming.test.ts` 只验通道 → arming 的委派，
   `computer-use-arming.test.ts` 验合成语义。原来那个 `shell-bridge-control-banner.test.ts` 的语义用例
   全部平移过去，不再重复两份。
- **两个半的收尾都只动自己那一半**：`render-process-gone` 与看门狗超时都调 `dropRendererSource(reason)`；
   退出流程里 `quitting` 仍然让渲染层的武装请求一律落空（工单 18 的守卫），daemon 那一半在退出时随链路
   断开自然归零。
- **本票不碰渲染层**：`useEmergencyStop` 与其心跳通道原样保留（并存期）。删除是 04，且必须在 03 发过一个
   release 之后 —— 否则老壳没有任何可退回的路径。
